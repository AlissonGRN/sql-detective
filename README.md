# SQL Detective

SQL Detective é um jogo educativo de investigação no qual o jogador resolve casos analisando dados de um banco de dados e construindo consultas SQL. Durante as investigações, é necessário explorar tabelas, interpretar resultados e relacionar evidências para chegar a uma conclusão.

O projeto foi desenvolvido para a disciplina **Interfaces Homem-Máquina (IHM)** da **Unidade Acadêmica de Serra Talhada (UAST), Universidade Federal Rural de Pernambuco (UFRPE)**, no curso de **Sistemas de Informação**. A proposta é aplicar conceitos de interação humano-computador em uma experiência prática de aprendizagem, com foco na orientação do usuário e na clareza da interface.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- SQL.js

## Como executar localmente

É necessário ter Node.js e npm instalados.

```bash
git clone https://github.com/AlissonGRN/sql-detective.git
cd sql-detective
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
